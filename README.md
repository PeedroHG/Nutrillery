# Nutrilerry 🌱

### ✨ Descrição

Desenvolvido como Trabalho de Conclusão de Curso (TCC) para o curso Técnico em Informática para Internet, este site permite que os usuários registrem suas refeições diárias, criando um histórico alimentar. Com isso, é possível acompanhar a dieta, identificar padrões e melhorar os hábitos alimentares para uma vida mais saudável.

### 📌 Funcionalidades principais:
✔️ Registro rápido de refeições com descrição e imagem <br>
✔️ Visualização fácil e intuitiva das refeições já cadastradas <br>

### ▶️ Como Executar Localmente

Instale as dependências:
```sh
npm i
```

Inicie o programa:
```sh
node .
```
O programa está configurado para rodar no link: http://localhost:8080/ e é necessário criar um banco de dados MySQL cujo script para criação está disponível aqui: [ScriptBD](bd.sql)
